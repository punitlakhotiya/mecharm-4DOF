# 2026-08-06: Research + Base completed

**Total time spent: 3.5 hours**

To develop my 3D modeling skills, I decided to build a robotic arm. I started by researching motor types, core concepts like degrees of freedom, and existing builds like https://forge.hackclub.com/projects/467. Drawing inspiration from that project along with various videos and reference images (example: https://www.youtube.com/watch?v=5Ielv6oBUnA), my first goal was designing the base.Along the way, I ran into several challenges—from learning how to use the Joint feature (https://www.youtube.com/watch?v=pX_pOBZjpLs) to enable smooth rotation, to using the Spur Gear generator (https://www.youtube.com/watch?v=DdCMjsYvVTc) and configuring all its parameters (pressure angle, module, tooth count, backlash, root fillet radius, gear thickness, and hole diameter). Even after dialing in the design, I encountered export glitches and extrude tool errors that required multiple rounds of troubleshooting. After overcoming these obstacles, I successfully CADded the finished base shown in the pictures. Image of todays CAD -  ![image.png](https://cdn.hackclub.com/019fd975-d77e-71bb-8d39-e06dc34984c6/image.png) The next step would most likely to be linkage from base to the actual body.
